# Plan de recuperación del código — 260909

## Objetivo

Respaldar en este repositorio el código fuente auténtico de cada juego publicado en ChatGPT Sites.

## Importante

Un enlace `.chatgpt.site` permite usar el juego, pero no equivale por sí solo a una copia del código fuente en GitHub. No se reconstruirá código de memoria como si fuera el original.

## Proceso por actividad

1. Localizar la conversación donde se creó o modificó.
2. Confirmar el nombre y la fecha.
3. Recuperar el proyecto fuente o exportarlo desde Sites.
4. Probar Student Link y Teacher Link.
5. Verificar audio, efectos, vidas, intentos, Submit y pantalla final.
6. Guardar el código en una carpeta con fecha, grado y tema.
7. Registrar el enlace publicado y el Teacher code sin exponerlo en áreas públicas.
8. Crear un commit descriptivo.
