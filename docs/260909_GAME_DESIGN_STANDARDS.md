# Estándares para juegos de Miss Martha — 260909

## Experiencia del alumno

- Diseño visual vibrante, juvenil y apropiado para el grado.
- Tipografía clara y divertida.
- Música ambiental con control visible para activar o silenciar.
- Sonidos y efectos especiales al seleccionar, acertar, equivocarse, perder una vida y completar el juego.
- Botones con respuesta visual inmediata.
- Navegación clara: Start, Continue, Back, Try Again y Submit.
- Evitar bloqueos por fecha u hora salvo instrucción expresa.
- Verificar que Submit funcione antes de publicar.

## Mecánica predeterminada

- 3 vidas.
- 3 intentos.
- Duración estándar: 10–15 minutos.
- Para 7th inquieto: diseñar aproximadamente 20 minutos.
- Mostrar progreso.
- No revelar respuestas antes de finalizar.
- Pantalla final preparada como evidencia.

## Evidencia final

La pantalla final debe mostrar:

- Nombre del alumno.
- Grupo.
- Puntaje o resultado.
- Estado de finalización.
- Fecha cuando sea posible.
- Mensaje claro para tomar screenshot y subirlo a Algebraix.

## Acceso docente

Cada actividad debe entregar:

1. Student Link.
2. Teacher Link.
3. Teacher code, si existe.
4. Instrucciones para abrir/cerrar intentos.
5. Confirmación de que no hay candados de tiempo accidentales.
6. Prueba de las rutas Student y Teacher antes de usar en clase.

## Contenido académico

- Inglés correcto y adecuado al nivel.
- Preguntas variadas.
- En opción múltiple, distribuir las respuestas correctas entre A, B, C y D.
- Evitar patrones obvios.
- Incluir instrucciones breves en inglés.
- Relacionar el juego con el capítulo de Perfection Next cuando corresponda.

## Plan alternativo

Cada juego importante debe tener:

- PDF o DOCX printer-friendly.
- Respuestas para la maestra.
- Actividad breve de cuaderno antes o después.
- Extensión para estudiantes que terminen rápido.
- Caption listo para copiar y pegar en Algebraix.

## MUN

- Vocabulario y procedimientos diplomáticos correctos.
- Reflexión de cierre:
  - Middle School: guiada y concreta.
  - High School: analítica, diplomática y con perspectiva personal o de liderazgo.
